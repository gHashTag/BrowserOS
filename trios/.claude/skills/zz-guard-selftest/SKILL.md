# DEAD FILE - inert tombstone, not a skill

This was a temporary self-test file for tools/clade-build-guard.mjs
(gHashTag/trios#1356), planted to prove the gate's failing arm from the
failing side, then meant to be deleted.

It could not be deleted: the tool that created it wrote it as root, the
shell runs as bee, and the image has no sudo, so unlinking a root-owned
file from a root-owned directory is not permitted. The content has been
overwritten with this tombstone so that nothing executable, instructable,
or gate-relevant remains. The directory contains only this file.

Safe to delete by anyone with root on this machine.
