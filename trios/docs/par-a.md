# Параграф A

Trios — это нативное macOS-приложение, построенное по архитектурному паттерну A2A Ring (Onion Layers). Каждый слой — Core, Infrastructure, Application, Presentation — имеет чёткую ответственность и зависит только от внутренних нижележащих слоёв. Core определяет доменные модели и протоколы; Infrastructure реализует транспорт, парсинг SSE и персистентность; Application управляет состоянием и бизнес-логикой через @MainActor ViewModels и акторы-конечные автоматы; Presentation отвечает за SwiftUI-представление. Такое разделение позволяет тестировать каждый слой изолированно, заменять реализации протоколов без каскадных изменений и сохранять кодовую базу читаемой по мере роста проекта.
