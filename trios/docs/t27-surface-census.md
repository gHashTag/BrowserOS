## Pairing rule

A .t27 spec pairs with any hand-written file whose basename (filename without extension) is identical to the spec basename, among extensions .rs .zig .c .v .swift .ts, anywhere under trios/ excluding node_modules, .worktrees, .claude/worktrees, .git and generated output (gen/ directories and "generated by t27c" banners). To check any row by hand: strip the extension from the spec filename and search the tree for that stem.

## Method

- Specs are every `.t27` file under `rings/`, walked naively first (worktree copies included — that is the number a hand count produces), then with worktree copies excluded, which is the census proper.
- Twins are hand-written files with extension `.rs`, `.zig`, `.c`, `.v`, `.swift` or `.ts` anywhere under `trios/`, excluding `node_modules`, `.worktrees`, `.claude/worktrees` and `.git`.
- Generated output is not hand-written code and is refused as a twin: files under a `gen/` directory, and files carrying a `generated by t27c` banner. Refused files are listed below.
- Line counts are `wc -l` semantics: one per newline, plus one for an unterminated final line.
- The tool uses the Node standard library only and reads nothing outside this tree; every path is derived from the script location. Nothing under `/Users/playra/t27` is read.
